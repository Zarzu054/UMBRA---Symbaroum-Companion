# Politica de privacidad de UMBRA20

Fecha de entrada en vigor: 1 de junio de 2026

UMBRA20 es una extension de navegador para Chrome que funciona como puente entre UMBRA - Symbaroum Companion y Roll20. Su objetivo es enviar tiradas o mensajes generados por UMBRA al chat de una partida abierta en Roll20.

## Datos que recopila la extension

UMBRA20 no recopila datos personales de los usuarios.

La extension no vende, comparte, analiza ni transmite datos personales a servidores del desarrollador ni a terceros.

## Acceso local a paginas

Para cumplir su funcion, UMBRA20 solicita permisos sobre:

- `https://umbra.z4rzu.com/*`
- `https://app.roll20.net/*`
- `https://roll20.net/*`

Estos permisos permiten que la extension actue como puente local entre una pestana de UMBRA y una pestana de Roll20. La extension puede leer mensajes generados por UMBRA y colocarlos en el chat de Roll20 cuando el usuario usa esa funcionalidad.

Este proceso ocurre dentro del navegador del usuario. UMBRA20 no envia esos datos a servidores propios de la extension.

## Datos almacenados

UMBRA20 no almacena datos personales de forma persistente.

Si en una version futura se guardan preferencias locales de funcionamiento, dichas preferencias se almacenaran en el navegador del usuario y no se enviaran al desarrollador ni a terceros.

## Uso de los datos

El acceso a la informacion de las paginas compatibles se utiliza exclusivamente para proporcionar la funcionalidad principal de la extension: conectar UMBRA con Roll20 y enviar tiradas o mensajes al chat de Roll20.

UMBRA20 no utiliza datos para publicidad, analitica, seguimiento, creacion de perfiles, venta de datos ni ningun otro proposito externo.

## Comparticion de datos

UMBRA20 no comparte datos de usuario con terceros.

## Servicios de terceros

UMBRA20 esta disenada para funcionar con UMBRA y Roll20. El uso de Roll20 y de UMBRA puede estar sujeto a sus propias condiciones y politicas de privacidad. Esta politica describe unicamente el comportamiento de la extension UMBRA20.

## Cambios futuros

Si en el futuro UMBRA20 incorpora funciones que recopilen, almacenen o transmitan datos de usuario, esta politica de privacidad sera actualizada antes de publicar dichos cambios. Tambien se actualizaran las declaraciones de privacidad correspondientes en Chrome Web Store.

## Cumplimiento de Chrome Web Store

El uso de la informacion recibida desde APIs de Google, si aplica, cumplira con la Politica de Datos de Usuario de Chrome Web Store, incluidos los requisitos de Uso Limitado.
